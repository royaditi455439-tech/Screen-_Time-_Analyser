# Screen-_Time-_Analyser
It is a simple python data analysis project which is helpful to analyse screen data and help you to track your habits also helpful reducing distraction.
## 📌 Project Overview

The Screen Time Data Analyzer uses Python and Pandas to analyze a week's worth of screen time and lifestyle data.

It calculates total and average daily screen time, identifies days with the highest and lowest screen usage, and summarizes average study and sleep hours.

The project also uses data visualization to make the results easier to understand.

## 🎯 Objective

The main objective of this project is to practice Python data analysis and visualization while exploring the relationship between screen time, studying, and sleeping habits.

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- Matplotlib
## 📊 Dataset Information

The dataset contains the following columns:

- `DAY` — Day of the week
- `Mobile_Hours` — Time spent using a mobile phone
- `Laptop_Hours` — Time spent using a laptop
- `TV_Hours` — Time spent watching television
- `Study_Hours` — Time spent studying
- `Sleep_Hours` — Daily sleep duration

## ⚙️ How It Works

1. Creates a dataset containing daily screen-time and lifestyle information.
2. Uses Pandas to organize and process the data.
3. Calculates total screen time for each day.
4. Calculates weekly and average daily screen time.
5. Identifies days with the highest and lowest screen usage.
6. Calculates average study and sleep hours.
7. Uses Matplotlib to create visualizations.
8. Displays the analysis results.
